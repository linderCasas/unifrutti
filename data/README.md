# Estructura de datos por área

Cada área guarda sus archivos fuente en una carpeta propia:

- `abastecimiento/` — libro del embalse Palo Verde
- `monitoreo/`
- `electromecanica/`
- `proyectos/`
- `infraestructura/`

Los reportes se incorporan en `templates/reports/` y sus rutas y lectores de datos se agregan en `app.py`. Las áreas futuras ya tienen su carpeta de datos preparada.
